連線設定

在儀表板上編輯的內容會直接存回你的 GitHub repo，需要一組只能存取這個 repo 的權杖（token）。權杖只會存在這台裝置的瀏覽器裡。

  1. 打開 GitHub 建立權杖頁面
  2. Token name 隨意填（例如 dashboard），Expiration 建議選 1 年
  3. Repository access 選「Only select repositories」，只勾這個 repo
  4. Permissions → Repository permissions：Contents 與 Actions 都設為 Read and write
  5. 按 Generate token，複製後貼到下方
